# 💧 Water Tracker

A dead-simple, no-signup, offline-first water tracking app.

**Live demo:** https://yourusername.github.io/water-tracker/

---

## What it is

Tap one big button every time you drink a glass of water. See your daily progress. That's it.

No account. No ads. No cloud. Your data stays in your browser.

## Features

- ✅ Set a custom daily goal (1–20 glasses)
- ✅ One-tap "+1 Glass" logging
- ✅ Visual progress ring
- ✅ 7-day history
- ✅ Auto-resets each day
- ✅ Works offline
- ✅ Installable on your phone (PWA)

## Why this exists

Most water tracker apps are bloated: sign-ups, subscriptions, ads, cloud sync you didn't ask for. This one does one thing well.

## Tech stack

- Plain HTML, CSS, JavaScript
- No frameworks, no build step, no dependencies
- Data stored in `localStorage`

## Run it locally

1. Download the files (`index.html`, `style.css`, `script.js`)
2. Open `index.html` in any browser

That's it.

## Deploy your own copy

1. Fork this repo
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch** → `main` → `/ (root)`
4. Your app is live at `https://yourusername.github.io/water-tracker/`
